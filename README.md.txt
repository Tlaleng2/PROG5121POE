# PROG5121POE - Part 1
## Registration and Login System

This project is a console-based java registration and login system
developed for the PROG5121 programming part 1 PoE.

## Features
-User registration 
-Username validation
-Password complexity validation 
-South African cellphone number validation
-User login 
-Successful and unsuccessful login messages
-JUnit testing

## Technology Used
-Java
-NetBeans
-JUnit 4
-Ham crest

## Testing
The application includes JUnit tests for the registration, validation
and login functionality.
All 7 tests pass successfully
